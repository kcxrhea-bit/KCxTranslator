# KCxTranslator

KCxTranslator is a Blizzard-safe multilingual MMO communication and translation system designed for real-time player communication workflows.

The project focuses on contextual translation, conversational filtering, MMO terminology handling, and local/manual translation workflows while remaining compliant with Blizzard addon limitations.

## Features

* Real-time multilingual translation workflows
* MMO-focused contextual parsing
* Blizzard-safe local addon architecture
* Context-aware phrase handling
* Conversational filtering logic
* Public/private channel handling
* Translation confidence and fallback systems
* Local dictionary architecture
* UI translation history and copy workflows
* Channel-specific translation controls
* Lightweight addon performance design

## Supported Workflow Concepts

* English ↔ Spanish communication
* Dungeon and raid terminology
* PvP and trade communication
* Social/conversational parsing
* MMO shorthand interpretation
* Channel-aware filtering
* Public-channel selective translation
* Manual-safe translation commands

## Technical Focus

* Lua addon architecture
* Contextual parsing systems
* Translation fallback pipelines
* MMO-safe workflow design
* Local-only translation systems
* Performance-conscious chat handling
* Modular dictionary organization

## Safety Philosophy

KCxTranslator is intentionally designed around Blizzard-safe workflows:

* no gameplay automation
* no memory reading
* no external gameplay control
* no unattended interaction
* manual user-triggered translation systems only

## Development Status

Active iterative development.

The addon is evolving toward broader contextual multilingual communication support while maintaining lightweight local-first workflows.
